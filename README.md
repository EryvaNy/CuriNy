# READ ME

Greetings, my name is **Eryva Nyren**. 

I’m a curious writer who think of each every story has a simple question behind it, “What if?” And it is the question that I create my stories, and characters.

My inspiration comes from small things, curious thoughts, and daily life of mine. Whether it’s a haunted house with some silly things, an incredible fictional character, or a world that is yet to be discovered, I am happy to create stories that will stay with the audience for a long time. 

This website is my personal information, here is another point on my journey as a writer. 

Thank you for checking my page and I hope you will discover something wonderful!
